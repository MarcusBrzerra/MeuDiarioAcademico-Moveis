# MeuDiarioAcademico-Moveis

Meu Diario Academico é um aplicativo para facilitar o cadastro de disciplinas do estudante na sua grade curricular

## Configuração

Para iniciar e configurar a estrutura base deste projeto, foi utilizado o seguinte comando no terminal:

1) Confirme Node.js LTS (>= 22.11): node -v
2) Crie o projeto:
```bash
   npx create-expo-app@latest MeuDiarioAcademico --template blank
```
3) Entre na pasta e inicie:
```bash
    cd MeuDiarioAcademico
   npx expo start
```
4) Abra no emulador Android ou no Expo Go.
